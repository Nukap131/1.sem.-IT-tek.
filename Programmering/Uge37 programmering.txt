Man deklarerer først variabler, derefter initialiserer det. Man initialiserer ved at give en værdi for variabler.

Eks:
#include <string>
string navn; // deklaration
navn = "Maria"; //En initialisering
string navn2 = "Giorgios"; //samtidig deklaration og initialisering.

int a, b, c, // Multiple deklaration
int column = 0, row = 0, index = 0; // multiple deklaration & initialisering.
